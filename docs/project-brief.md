# Project Brief: NeoCode

## Problem
- **Who is the user?** Developers using AI coding assistants
- **What pain is urgent + expensive?** Need better integration between planning and code execution

## Promise (Painkiller)
- In 1 sentence: Unified platform for plan-code-mode workflow (planning → code generation → execution)
- What is the narrow wedge? Focus on seamless transition from planning to code

## ICP
- **Role:** Software developers, AI-assisted coding practitioners
- **Context:** Using multiple tools (Claude, opencode, etc.) and need unified workflow
- **Budget:** Developer tool pricing ($20-50/month)
- **Trigger:** Frustrated with context switching between planning and coding tools

## MVP Scope (14 days)
- **Critical path:**
  - Plan capture and storage
  - Code generation integration
  - Execution tracking
  - Context preservation
- **Out of scope:**
  - Multi-user collaboration
  - Advanced analytics

## Pricing Hypothesis
- **Price:** $29/month for individuals, $99/month for teams
- **Packaging:** Individual: personal workflow, Team: shared plans + collaboration

## Risks / Assumptions
- Top 3 assumptions to validate first:
  1. Developers will pay for workflow tool (vs free alternatives)
  2. Integration with multiple AI tools is valuable
  3. Plan-code workflow is a real pain point

## Status
- **Intake Date:** 2026-01-20
- **Stack:** Node.js, TypeScript
- **Repository:** Active git repository with code
